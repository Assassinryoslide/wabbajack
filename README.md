# Wabbajack

### Automated modlist installer for Bethesda games

Wabbajack enables the creation and installation of fully-reproducible modlists for Skyrim, Fallout, and other supported games. Install a professionally-curated thousand-mod setup in hours with zero manual configuration.

<br>

---

## Features

| | |
|:---|:---|
| **One-Click Install** | Install 1000+ mod setups automatically with verified file matching |
| **Gallery of Lists** | Browse dozens of community-curated modlists sorted by theme and difficulty |
| **No Manual Steps** | Completely automated — no copying files, no manual patches |
| **Reproducible** | Every installation matches exactly the list author's configuration |
